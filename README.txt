วิธีติดตั้ง TLR Transport Report v10.0
1. เข้า github.com และสร้าง repository ชื่อ tlr-transport-report แบบ Public
2. อัปโหลดไฟล์ index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png ในโฟลเดอร์หลัก (ไม่อัป ZIP อย่างเดียว)
3. Settings > Pages > Deploy from a branch > main > /(root) > Save
4. เปิด https://pissanu023-lang.github.io/tlr-transport-report/ หลัง GitHub Pages สร้างเว็บสำเร็จ
5. เปิดใน Safari ครั้งแรกโดยใช้อินเทอร์เน็ต แล้วเพิ่มไปยังหน้าจอโฮม
6. ทดสอบโหมดเครื่องบินหลังเปิดหน้าเว็บออนไลน์จนโหลดเสร็จแล้ว
7. ข้อมูลเก่าไม่ย้ายอัตโนมัติ ให้กด สำรอง JSON จากรุ่นเก่า แล้วเลือก นำเข้า JSON ที่เว็บใหม่
8. สำรอง JSON ประจำ และเก็บสำเนาในเครื่องอื่นด้วย
